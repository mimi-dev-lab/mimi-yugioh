# 游戏王插件：要验证什么

都在 `/yugioh`（侧栏「游戏王」），是一份烙印教程，只读。`scripts/plugin-smoke.sh` 覆盖下面标 ✔ 的。

## 外壳
- ✔ 标题「游戏王 · 烙印教程」，四个页签：卡组一览（第一个，默认打开）、展开路线、起手速查、术语表（第四个）。
- ✔ 页面上没有旧功能的字样，也没有百分比（词表见 `scripts/plugin-smoke.sh` 的 `OLD=`）。

## 卡组一览
- ✔ 顶上一行：卡组名、主卡组 40 张、额外卡组 15 张、卡表出处（Game8 的版本日期，链过去）。
- ✔ 按默认作用标签（每张卡的第一个词）分组：初动、检索、素材、打断、手坑等，每组写张数和一句含义；每张卡下面是它的默认作用标签（彩色小块，悬停有原因）。
- ✔ 术语表页签（`--tab 术语表`）：每个作用词一块（颜色、解释、默认是这个作用的卡有几种）；手机宽也能看。
- ✔ 每张卡：卡图、简中名（`md_name`）、日文名；多张标 ×N，额外卡组的标「额外」，有打断的标「打断 N」。
- ✔ 点卡（`shot NAME --select 卡名`）：说明区出大图、两个名字、作用、在哪个卡组几张、干什么 / 条件代价 / 限制、对手回合（终场时能打断几次和怎么打断；手坑写「从手牌发动」；别的写「终场时不提供打断」）、「关上」。再点一次、「关上」或 Esc 收起。
- ✔ 手机宽（`--mobile`，390×844）：页签占满一行，卡图小一号，点卡后说明从底部弹出；不出横向滚动条。

## 展开路线
- ✔ 作用标签：步骤面板和终场汇总里「中场的卡和它们此刻的作用」，每张中场卡有缩略图、彩色标签、一句此刻的原因（整句可见，手机宽也看得到；标签悬停有 title），沿用的标「自第 N 步起」；卡片弹窗里有「第 N 步」这一行和「默认作用」。
- ✔ 场面上的作用标签：路线动画里中场的每张卡、手牌里此刻有作用的卡（手坑、终场算打断的墨丘利耶）在卡面下沿带作用标签。每张路线截图的 `.json` 有 `stage`（`yg-rects` 量的卡和标签位置，`detached` 是没贴在卡上的标签，非空就失败）；`--require-roles` 要求至少一块；`--hover-role 卡名` / `--tap-role 卡名`（手机）悬停 / 点标签，等原因小框 `.yg-roletip`（`.json` 的 `roleTip`）；`--clip-stage` 只截动画框（场面特写）；`--stage-at K:比例` 和 `--next-mid` 截播放中的帧。
- ✔ 积木：步号条按积木分段着色（每段一块积木：颜色线、积木名、本段的步号，亮着的步号涂这块的颜色）；步骤面板和终场面板在步骤说明下写当前积木的名字、「第 a–b 步 · 这块的第 k / m 步」和「要什么 → 给什么」（手机宽上下排）；起手面板列这条路线的所有积木。先猜再看开着时，还没播到第一步的积木不写名字、面板也不出积木卡片。每张路线截图的 `.json` 有 `blocks`（分段的名字、颜色、步号，面板里的积木卡片、起手面板的积木 id 列表）；`plugin-shot` 每张路线截图都查：步号从 1 连到最后不漏不重，相邻两段颜色不同，面板里的积木就是亮着的步号所在的段；`--require-blocks` 要求一定有分段。
- ✔ 资源账本（试用）：步骤面板和终场面板里「资源账本」一块：通常召唤（还没用 / 已用（第 N 步））、「每回合一次的效果 · 已用 N 个」（卡名＋①②③＋一句话，这一步新用的标「新」）、「额外卡组 · 剩 a / b 张」和关键卡（冰剑龙、击铁龙、三英的相剑师）在不在；数据来自 `steps[].ledger`，服务用 `YUGIOH_FEATURES_OFF=ledger` 启动时整块没有。先猜再看开着、还没揭晓的那一步不显示。
- ✔ 列表（`shot NAME --tab 展开路线`）：每条路线写名字、需要的起手卡（卡图 + 简中名）、终场打断数、步数、来源（Game8 + 页面版本日期）、引擎验证日期；有 mismatch 的路线再标「和教程不一致」。
- ✔ 播放页（`shot NAME --route ID或名字 [--step N|起手|last] [--keys]`：点列表里的路线，默认停在起手，再一步步点「下一步」；`--keys` 改按右方向键）：顶上来源链接、页面版本、引擎验证于；有 mismatch 时醒目的橙框「教程和引擎不一致」；步号条（最前面是「起手」，点任一号跳步）、上一步 / 下一步、「第 N / 总数 步」（桌面宽吸在顶上）；场面是路线动画（见下一节）；右边是步骤面板（样子稿 C）：进度条、大步号、按动作着色的标签（同调浅蓝、融合粉、别的灰）、这一步的说明、花了什么 → 换来什么（卡图 + 「场上→墓地」这样的去向）、发动了什么、墓地 / 除外几张和哪些卡、折叠的引擎里的操作。
- ✔ 起手（第 0 步，打开播放页的默认位置）：起手场面（手牌 5 张）和「起手 · 共 N 步」，没有「花了什么」差异区块；左右键、上一步 / 下一步把它包含进去。
- ✔ 最后一步（`--step last`）：右边的面板换成「终场」：黄色大号打断数 +「个打断」、「靠这些卡」每个打断一条（卡图、怎么打断）、剩余手牌、墓地 / 除外（`.yg-end`）。
- ✔ 步号条和按钮没被盖住：`.json` 的 `bar.clear` 为真（每个按钮上下沿的 elementFromPoint 落在按钮自己身上；冒烟查 hover-route、anim-mid、route-mid）。
- ✔ 路线动画（动画框：`SandboxedFrame` 里的 HyperFrames 页）：
  - 下一步播这一步的动画然后停住（`--step N` 每点一下都等播完 `data-mode=idle`）；点步号（`--click-step N|起手`）直接跳到那一步的结束帧，不倒放；连播（`--play-all`）从当前步播到终场并停住，json 的 `playedMs` 是用时；左右键同按钮。
  - 中间帧（`--stage-at K:比例`）：把动画跳到第 K 步的这个比例处停住再截图，取同调 / 融合的中间帧；要页面控件也是真的中间状态时用 `--step K --next-mid MS`：走到第 K 步后点「下一步」，动画播了 MS 毫秒就截图，步号条显示 K+1、动画框是第 K+1 步的中间帧（`--stage-at` 只 seek 动画框，控件还停在原来的步）。
  - 每个位置结束时场面和快照一致（`test/anim-plan.test.js` 对每条路线每一步逐张查）；守备表示的怪兽横放（第 9 步阿卢绯尔）；特效不盖卡名和区域标签。
  - 悬停（`--hover-anim 卡名`，手机 `--tap-anim 卡名`）：动画框报告每张看得见的卡的位置，再用真鼠标 / 真触摸点过去，弹窗和别处同一个。
  - 不联网：json 的 `cdp` 是这个标签页和它的子框架（动画框）发的每个请求（`--net-file FILE` 把清单写到文件，非本地的标出来），`cdp.foreign` 必须是空的。
- 手机宽（`--mobile`）：动画和面板上下排，大步号小一号，不出横向滚动条（冒烟查 `overflowX`）。
- 数据来自服务启动时的引擎重放（`YUGIOH_ENGINE`，`yv launch` 默认用 `~/.cache/mimi-yugioh/engine`）；引擎数据缺失时 `/routes` 回 503，页面在页签里显示错误。
- 不查：mismatch 的橙框（现在每条路线都和教程一致，没有这个状态；接口测试 `test/route-view.test.js` 用构造的路线守着机制）。

## 起手速查
- ✔ 页签（`shot NAME --tab 起手速查`）：每张关键卡一块（白之落胤、烙印融合、阿卢绯尔、天底的使徒、白之圣女、烙印之气炎）：卡图 + 简中名 + 日文名；「手里有它：走」下面是路线按钮（路线名、终场打断数、步数；烙印之气炎的两条标「搭 X」）；「缺 X　手里有 Y → 路线」几行，每行一个路线按钮和一句为什么走得通。数据来自 `GET /routes` 的 `lookup`，只指向已有路线。
- ✔ 点路线按钮（`shot NAME --tab 起手速查 --jump ID [--step N|last]`）：跳到「展开路线」页签里那条路线的播放页，停在起手（第 0 步）。
- ✔ 手机宽（`--mobile`）：长图，不出横向滚动条。

## 卡片弹窗
- ✔ 桌面（`shot NAME --hover 卡名 [--within CSS] [--close]`）：鼠标移到卡上弹出放大卡图、简中名和日文名、作用、干什么 / 条件代价 / 限制、对手回合；卡组一览、路线动画里的卡（`--hover-anim`）、终场面板（`.yg-end`）、起手速查（`.yg-lookup`）都有；整块在窗口里（json 的 `pop` 是弹窗矩形和窗口大小）；Esc 收起（`--close`）。
- ✔ 手机（`--mobile --tap 卡名 [--close]`；动画里的卡 `--tap-anim 卡名`）：触摸点一下从底部升起，带「× 关上」，点它关上，再点又出来，Esc 也关。
- 卡组一览在手机上点卡（`--mobile --select 卡名`）也是这个弹窗（带「× 关上」），页面里的说明区不开，同一时刻只有一个详情界面。

## 卡图
- 页面经 `GET /card-image?code=` 拿 JSON(base64)，拼成 data: 地址；没有这张图时在卡图位置写卡名。
- 冒烟用编的单色小图；给用户看的截图用真卡图（`up --images`）。

## 展开地图（#50，试用）
- ✔ 页签（`shot NAME --tab 展开地图`）：块的标题「汇流地铁图」、一句说明、一排「只看」路线按钮、地铁图：左边起手站，中间积木站（「枢纽 · N 条路线」），右边 9 个终场站（路线名、打断数）。`.json` 的 `map`：站数、终场站数、边数、`outside`（画在图外的站，必须空）、`scrolls`（图比外框宽）。
- ✔ 点站（`--station 站id [--stop 路线id]`，站 id 如 `block:opening-bridge`、`start:68468459`、`end:white-albaz`）：只一条路线经过的站直接跳到「展开路线」页签的播放器，停在那一步；几条路线经过的先在图下面出「跳到哪条路线的哪一步」，`--stop` 指一条再点。`.json` 的 `mapJump` 是点的那条路线和步号。
- ✔ 手机宽（`--mobile --tab 展开地图`）：整页长图；图在外框里左右滑，页面不出横向滚动条（`overflowX` 为 false，`map.scrolls` 为真）；「只看」那排按钮一行横滑。
