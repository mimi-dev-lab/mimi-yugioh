# 游戏王插件：要验证什么

都在 `/yugioh`（侧栏「游戏王」）。`scripts/plugin-smoke.sh` 覆盖下面标 ✔ 的。

## 首页
- ✔ 三个页签：首页、记卡、记录（记卡、记录现在是占位）。
- ✔ 「开始一手」：`$P shot s --design --start`。服务里已有一手时多一个「继续这一手」（`up --hand-seed 37` 后 `--resume`）。

## 首页（对照 design-r3/clock-home.png）
- ✔ 散点（用时 × 场面，按起手类型着色，标个人最好和刚才）、速度加成区按线性规则画（60 秒内 +20、5:00 降为 0，不画 1:30 / 2:30 / 3:30 分档）、「开始一手」、到期记卡数、个人最好、各类起手的平均场面和用时、最值得练一句、基准手的进步曲线。
- ✔ 三种数据状态：`$P up --made-up-hands 0|1|127` 后 `shot NAME --design --compare ~/work/.preview/yugioh/design-r3/clock-home.png`（编的结算记录，每 5 手里有 1 手基准手，基准手不画点）。

## 展开中屏（对照 design-r3/clock-play.png）
- ✔ 计时器从发牌开始走；「提示 0 次 · ×1.0」；「场面分在结束回合后才揭晓」；没有百分比、「还差」、估值。
- ✔ 操作记录：步、时间、操作、花了 → 换来；最后一行「轮到你」。
- ✔ 场地：召唤权、已生效的限制（橙色）、怪兽区（含两个额外怪兽区）、魔陷区、场地魔法、额外 / 除外 / 卡组的张数、墓地（点它列出所有墓地的卡）。
- ✔ 额外卡组、除外区、墓地：点开是卡列表（卡图 + 卡名），有合法操作的卡带绿点，区域按钮上也有；点卡后列表关上，详情区出现它的操作（额外卡组里的是「额外卡组特殊召唤」）。`shot NAME --design --resume --route white-albaz --route-steps 2 --open 额外卡组`，再 `--open 额外卡组 --pick-in 黑衣龙之艾克利西亚`。
- ✔ 「进结束阶段」：主阶段有结束回合选项时详情区下方的按钮；结束阶段的效果（回手、检索）由你在浮层里选，之后「结束回合」放过剩下的。
- ✔ 只用页面点击走完一条路线：`shot NAME --design --resume --route white-albaz [--route-from N] [--route-steps N] --end`（种子 37 的手）。
- ✔ 手牌：卡图下写 Master Duel 简中名；有合法操作的卡右上角一个绿点。
- ✔ 点卡：右边显示名字、角色、可做的操作按钮、干什么 / 条件代价 / 限制（`--select 天底的使徒`）。
- ✔ 点操作按钮：`--select 白之落胤 --do 发动`；引擎要选的东西用卡图列在中间的浮层里（`--answer N` 回答）。
- ✔ 「提示」按钮写明「分数 ×0.8」；点一下照提示走下一步，提示次数变 1（`--hint 1`）。
- ✔ 「结束回合」：`--end`，出结算屏。

## 结算屏（对照 design-r3/clock-result.png）
- ✔ 场面分 + 速度加成 × 提示系数 = 总分，各一格并写组成（打断 x/最好，手牌 x/最好；没到 90 写「不计」和原因；提示次数和用提示的步；这类起手的平均）。图上不画 1:30/2:30/3:30 分档，规则以规格 #1「评分」为准。
- ✔ 「每一步之后的场面」曲线：白 = 用户、绿虚线 = 最好路线，标走偏那一步。
- ✔ 最好终场和你的终场并排，缺的卡位用虚线框标出。
- ✔ 逐步对照：每步两边做了什么、花了什么换来什么，用提示的步标出；末尾写基准来源。
- ✔ 「再来一手」（新随机）、「重打这一手」（同样 5 张牌：`--replay`）。
- 并排对照：`shot NAME --design --resume --answer 14 --end --compare ~/work/.preview/yugioh/design-r3/clock-result.png`。

## 记卡（对照 design-r3/clock-cards.png）
- ✔ 记卡页签：「N 张卡到期」、「开始记卡」；没有到期的卡时按钮是灰的。
- ✔ 一道题：本题已用（计时条、5 秒标记、上次用时）、这张卡的答题用时、「n / 总数 · 还剩」、「结束」。三种题 `--quiz-start --quiz-kind identify|fill|find`。
- ✔ 答题：`--quiz-answer N` 用数字键 1（和 identify 的 5）选、回车提交；反馈写对错、评分、下次多久后再考、三件事；回车下一题。
- 并排对照：`shot NAME --design --tab 记卡 --quiz-start --quiz-kind identify --compare ~/work/.preview/yugioh/design-r3/clock-cards.png`（给用户看的用 `up --images` 的真卡图）。

## 卡图
- 页面经 `GET /card-image?code=` 拿 JSON(base64)，拼成 data: 地址；没有这张图时在卡图位置写卡名。
- 冒烟用编的单色小图；给用户看的截图用真卡图（`up --images`）。
