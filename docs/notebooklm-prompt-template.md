# NotebookLM 卡组教学生成提示词

## 使用方法
1. 在导入页面点击「NotebookLM 提示词模板」展开
2. 复制提示词，替换【卡组名称】
3. 发送给 NotebookLM
4. 将回复粘贴到导入页面

---

## 提示词内容

```
请为【在此输入卡组名称】生成一份卡组教学文档。

## 格式要求

### 卡表格式（每张卡必须这样写）
- 3x **English Card Name** (中文卡名) [角色]

角色标签只用这些: [核心][初动][展开][终端][手坑][检索][保护][去除][泛用]

### 需要包含的内容

1. **打法思路** - 3-5句话概括核心战术

2. **卡组列表** - 分主卡组/额外卡组，每张卡都要有英文名和角色标签

3. **起手判断**
   - ✅ 理想起手（2-3种情况，写明需要哪些卡，能做出什么场）
   - ⚠️ 勉强能打（写明条件和预期结果）

4. **Combo 教学**（给5个常用Combo）
   - 起手要求（需要哪些卡）
   - 详细步骤（每步写出英文卡名和中文卡名）
   - 最终场面（场上有什么、盖了什么、墓地有什么资源）

5. **小技巧**（3-5个进阶技巧）
```

---

## 为什么这样设计

1. **英文卡名** - 用于精准匹配数据库，避免翻译差异问题
2. **角色标签** - 帮助快速理解每张卡的作用
3. **5个Combo** - 覆盖常见起手和变化
4. **无手坑分析** - 简化学习曲线
5. **无换牌建议** - 游戏王没有换牌机制
6. **无对局指南** - 后续可单独学习
